## Что умеет Kadr

**Kadr** — это быстрый и компактный медиаредактор без перегруженного интерфейса. Открывается мгновенно и подходит для повседневных задач с фото, видео и аудио:

- **Фото** — просмотр, обрезка, поворот и отражение, базовая цветокоррекция (яркость, контраст, насыщенность) и сохранение в `PNG`, `JPG`, `WebP`.
- **Видео** — плавный просмотр, точная перемотка по кадрам/времени, обрезка нужного фрагмента и быстрый экспорт.
- **Аудио** — проигрыватель с визуализацией дорожки, регулировкой громкости (включая усиление до 300%), плавным появлением/затуханием и обрезкой.

## Установка

1. Перейди на страницу [**Releases**](https://github.com/penereya/Kadr/releases/latest).
2. Скачай **`KadrSetup.exe`** и запусти установщик — он установит программу и создаст ярлыки на рабочем столе и в меню «Пуск».
3. Или скачай **`Kadr.exe`**, если хочешь пользоваться портативной версией без установки.

> [!NOTE]
> Для работы с видео и аудио приложение использует `ffmpeg`. Если он уже установлен в системе, Kadr найдёт его автоматически.

## Сборка из исходников

Если хочешь собрать проект самостоятельно (понадобится установленный [Rust](https://www.rust-lang.org/)):

```bash
cargo build --release --bin kadr
```

Готовый файл появится в `target/release/kadr.exe`.
